```

/resume           简历 —— 从 PDF 导入的结构化页（可打印）
/blog             Blog 列表 —— 文章卡片（标题/日期/摘要）
/blog/[slug]      文章详情 —— MD/MDX 渲染

```

## 3. 页面验收标准

### 首页 `/`

| # | 标准 |
|---|---|
| H1 | 展示名 daner + 简短定位（训推/Agentic RL 等，文案可后调） |
| H2 | 明显入口到「简历」「Blog」 |
| H3 | 可见联系：`minutiadaner@163.com`（电话可放简历页为主） |
| H4 | 无死链；本机 `dev` 打开即达 |

### 简历 `/resume`

| # | 标准 |
|---|---|
| R1 | 内容来自 PDF 导入的 MD，非纯假数据；关键经历/教育/技能/论文可见 |
| R2 | 联系：邮箱 + 电话与源一致 |
| R3 | 版式适合屏幕阅读；`@media print` 可打印为一份干净简历（无导航干扰或打印隐藏导航） |
| R4 | 区块标题清晰；长列表不溢出半屏无结构 |

### Blog 列表 `/blog`

| # | 标准 |
|---|---|
| B1 | 至少 1 篇文章卡片（可先 1 篇占位文，但管线支持新增 MD） |
| B2 | 卡片含标题、日期、摘要；点击进详情 |
| B3 | 无文章时有空态（本轮有 1 篇则可不测空态） |

### 文章 `/blog/[slug]`

| # | 标准 |
|---|---|
| A1 | MD/MDX 正文正确渲染（标题、段落、代码块若有） |
| A2 | 有返回列表 |
| A3 | 未知 slug → 404 |

### 工程（产品口径）

| # | 标准 |
|---|---|
| E1 | README：`dev` / `build` 命令清晰 |
| E2 | 无写死本机绝对路径于构建产物；部署仅 stub |
| E3 | 不擅自对外发布；群内甩 localhost 地址即可 |
