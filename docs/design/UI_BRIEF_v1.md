## 2. 已锁定（勿回退）

## 4. 不做（红线）

1. 不开第二套色板 / 暗亮切换  
2. 不加光效、插画墙、粒子、Hero stagger  
3. 技能不变彩色 tag 墙  
4. 不改业务内容口径；教育段后移与元注释清除交内容/工程  
5. 结构大拆等 IA；本 Brief 不重开信息架构

## 5. 与内容门禁的边界

| 门禁 | 谁 | UI 角色 |
|---|---|---|
| `main.md` 教育挪到技能后 | 内容/工程 | 验版式是否仍稳；不改 MD 文案 |
| 可见元注释清零 | 内容/工程 | 外发前视觉抽检；发现灰说明即打回 |
| 清完前不外发链接 | 主管/测试 | UI 不主动给对外链 |

## 6. 验收（UI 过/不过）

**过：** 首页不像模板；简历屏上清晰、打印白底；Blog 安静；中文标题无衬线跳变；动效不抢内容。  
**不过：** 又加光/第二母题；对比度回退；私开第二套视觉。

## 7. 建议节奏

1. 内容门禁清完前：**UI 待命微调**，不排大改。  
2. 门禁清后：按 U1–U4 扫一遍本机打印 + 三页抽检即可锁版。  
3. 负责人若另有改版旨意，以设计总监 Brief 为准，本文件让路。
