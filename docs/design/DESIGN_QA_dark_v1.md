- 首页 badge / 双 CTA / tag 节奏清楚
- 简历进卡片容器，屏上扫描更好
- `@media print` 回白底并藏导航 —— 保留

## 请改（按优先级）

### P0 · 可读

1. **简历正文对比度**：`.resume p / li` 现在吃 `text-muted`，长技术 bullet 发灰。正文改用 `--text`，次要 meta 才用 muted。  
2. **教育元注释**：屏上仍是「乱码/以 PDF 为准」——视觉再高级也像半成品。内容清掉前，设计裁定：**不外发**。

### P1 · 高级感（去一点「模板光」）

3. **减弱双径向光晕**：背景 glow 各降 ~30%，避免 AI 模板感。  
4. **主按钮**：线性渐变 + 大 shadow 可收一档；实心 mint / 白字也够高级。  
5. **中文标题字体**：`Fraunces` 对中文会回落宋体，中英混排易跳。建议 display 仅包英文词，中文标题走 `Sora`/系统 Sans。

### P1 · 移动

6. **640 以下**：hero 标题 `clamp` 下限略降；导航 pill 防换行拥挤（可减 padding 或改成文字链）。  
7. **简历卡片**：小屏左右 padding 已有，确认长代码/`torch.autograd.Function` 不撑出横向滚动（`overflow-wrap: anywhere`）。

### P2

8. Blog 卡片与简历卡片圆角/边框统一同一 token（已接近，扫一眼即可）。  
9. 页脚邮箱与简历联系方式字号层级统一。
