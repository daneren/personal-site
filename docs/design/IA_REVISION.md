## 1. 全局路径（访客 30 秒）

> **v1.1（老板裁定）**：简历与 Blog 都要，**Blog 优先**。招聘路径仍保留为次 CTA / 顶栏「简历」。

| 步 | 预期动作 | 设计意图 |
|---|---|---|
| 1 | 顶栏或首页读到「谁 + 做什么」 | 3 秒定位 |

## 2. `/` 首页 · 层级修订

### 现状问题

活站叠了 **badge → H1 → lead → 4 tags → 双 CTA**，层数偏多；Brief 要求记忆点 = **字标 + 一句锋利定位 + ≤3 能力词**。

### 目标层级（自上而下，只留这些）

```
logo（壳层已有，页内勿再重复大字标）
H1  一句锋利定位（中文可断行，≤2 行）
lead  一句补充：谁 / 在哪 / 这站放什么（≤2 句；点明「工程笔记」为主）
能力词  ≤3（文本，非 chip 墙；UI 已去 pill）
主 CTA  阅读 Blog
次 CTA  查看简历
最新一文  可选一行链接（标题 + 日期），非卡片墙
```

### 文案结构建议（口径可微调，层级锁死）

| 槽位 | 建议 | 不做 |
|---|---|---|
| H1 | 保留锋利句，如「把复杂训推系统跑稳、跑快。」 | 勿再加上方 badge 行（与 H1/能力词重复） |
| lead | 「YouTu / TI · 大规模训推 infra + Agentic RL。简历与工程笔记。」 | 勿写成第二段小作文 |
| 能力词 | `Training Infra` · `Agentic RL` · `Inference`（三选三；删掉第 4 个 `LLM Systems` 或并入 lead） | 禁止 ≥4、禁止彩色 tag 墙 |
| CTA | 主：Blog；次：简历（实心主按钮对齐 Brief） | 勿加第三按钮 / 项目集入口 |

### 给 UI 的结构改动（小）

- 去掉 `.hero-badge`（或并入 lead，不单独占一层视觉）
- `.hero-tags` 截断为 3；样式跟 Brief（非 pill 墙）
- 不引入首页精选文章卡、插画、第二列（本轮）

## 3. `/resume` · 区块顺序与扫读

### 现状问题

`main.md` 顺序为 **教育 → 经历 → 技能 → 论文 → 荣誉**。对已工作多年的 infra IC，招聘扫读路径应 **经历优先**；教育靠后即可。

### 目标区块顺序（屏上 = 打印）

1. **头**：姓名 · 邮箱 · 电话（一行内，打印可见）  
2. **经历**（主栏，信息密度最高）  
3. **技能**（文本块，非 tag 墙）  
4. **教育**  
5. **论文**  
6. **荣誉**（可折叠观感：短列表，勿升成主章节视觉重量）

### 经历内部层级（保持 MD，强化扫读）

```
### 公司 · 组 · 城市 · 起止
一段总述（≤3 行）
#### 项目/主题 · 起止
- bullet（结果量级优先；「见 PDF」类元注释禁止出现在可见文）
```

规则：

- `h2` 只用于五大区块名（经历/技能/教育/论文/荣誉）  
- `h3` = 雇主行；`h4` = 项目行 —— 方便 UI 做字号阶梯，避免「一片同级标题」  
- 单雇主下项目 **按时间倒序**（已大致如此，保持）  
- 不把技能拆成独立彩色 chip；保持 `- **语言**：…` 文本块

### 内容门禁（设计卡外发，执行归内容/工程）

可见字里不得出现：元注释、占位灰字、「以 PDF 为准」、乱码、未替换的导入残留。  
口径数字不擅自改（Brief §5.7）。

## 4. `/blog` · 列表与详情

### 列表

现状已接近 Brief：标题 / 日期 / 摘要，无封面墙。锁定：

- 页题 `Blog` + 一行 muted 说明即可  
- 卡片整卡可点；日期用 `--text-muted`  
- 空态：若 0 篇，一句「暂无文章」+ 回首页链（有文可不做）  
- **不做** 分类、标签云、封面图、侧栏

### 详情 `/blog/[slug]`

- 保留 `← 返回 Blog`（当前态）  
- 标题 → 日期 → 正文；栏宽跟散文栏（720–760）  
- 文末不加「相关文章」墙（本轮）

### 与首页关系

Blog 是 **主路径**：首页主 CTA + 顶栏「Blog」。  
允许首页 **一条**「最新一文」文字链（降低空列表感）；**禁止** 首页嵌入多篇卡片/双列（仍避免双焦点变墙）。

## 7. 验收（UX 过/不过）

**过**

- 首页 ≤4 个内容层（H1 / lead / ≤3 词 / CTA），3 秒能复述定位  
- 从首页一键进 Blog（主按钮）；简历仍一键可达  
- 简历首屏即联系+经历，不必先翻教育  
- Blog 安静，返回路径清晰；首页最多 1 条最新文链  
- 无新增页面、无项目集入口

**不过**

- 首页主按钮仍指向简历（与 Blog 优先冲突）  
- 首页又加 badge/第四能力词/多篇文章双列  
- 简历仍教育置顶或技能变 tag 墙  
- 为「丰富」加 `/projects` 或首页模块墙
