## 1. 首页双栏信息层级

### ≥900px

| 栏 | 只放 | 禁止 |
|---|---|---|
| 左 `.hero-statement` | **仅 H1**（≤2 行锋利定位） | lead / tags / CTA / 最新 |
| 右 `.hero-rail` | 名 → 角色 → lead≤2句 → 3能力（`·` 串）→ **主次 CTA 竖叠** → 最新一文（1 条） | 卡片底、第二装饰、文章列表墙 |

### CTA 主次（老板 v1.1）

1. **主** `btn-primary` → `/blog`「阅读 Blog」  
2. **次** → `/resume`「查看简历」  
3. 最新一文：文字链，非第三按钮

### <900px

单栏序：H1 → 名/角色可并入或省略重复名 → lead → 能力 → CTA（可横排，主仍 Blog）→ 最新。

### Lead 口径

点明「工程笔记为主，简历可查」；勿再写成简历优先话术。

## 2. 简历扫读路径

```
resume-head（左名+角色 / 右邮+电）
→ 经历（雇主头 1 条 + 项目条按开始年倒序）
→ 技能（两列文本）
→ 教育（年份轨）
→ 论文 → 荣誉
```

### 年份轨规则

| 块 | `.job-year` | 说明 |
|---|---|---|
| 雇主头 | 入职年（如 `2021`） | 组织锚点，可置经历区顶 |
| 项目条 | **项目开始年** | 同雇主下按开始年 **倒序** |
| 教育 | 入学年 | 教育整段在技能后 |

扫读预期：眼沿左轨下滑，右栏 h3→meta→bullet；bullet 紧、块间疏（跟 UI Spec）。

### 不做

- 技能 tag 墙  
- 经历下再套大卡片  
- 改口径数字（内容门禁另线）
