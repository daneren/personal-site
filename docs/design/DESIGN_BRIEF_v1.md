## 0. 现状裁定（为什么不合格）

活站已从浅色脚手架漂到深色「作品站」，气质比脚手架强，但仍像 **2024 AI 作品模板**：双径向 glow、渐变 CTA、pill 导航/标签墙、Fraunces 对中文回落宋体。简历容器好看，但正文对比度不足、元注释仍像半成品。  
另：仓库里浅色基线与深色 QA **两套定稿并存**，执行会各改各的。本 Brief **锁死唯一方向**，旧基线仅保留「可读/可打印」原则。

## 1. 设计方向（一句话）

**系统工程师的暗色编辑站**：克制、可信、可打印；首页有一句可记住的签名；简历像纸、Blog 像干净刊物。精致靠字距/层级/留白/一处品牌签名，不靠光效堆料。

气质关键词：`editorial` · `systems` · `quiet confidence` · `print-ready`  
反关键词：`SaaS landing` · `AI portfolio glow` · `tag wall` · `gradient CTA`

## 2. 目标验收（今天对外门槛）

| 页 | 必须达到 |
|---|---|
| `/` | 3 秒内读懂「谁 + 做什么」；有记忆点（字标/一句定位），无模板光 |
| `/resume` | 屏上正文高对比、可扫读；打印白底藏 nav/footer；无任何元注释/占位灰字 |
| `/blog` · 详情 | 干净列表与正文栏；无封面图堆砌；返回路径清晰 |

总闸：**清元注释 + 简历正文对比度过关前，不外发链接。**

## 3. 视觉系统（锁 token，改前先对齐）

### 色（屏上）

| Token | 值 | 用途 |
|---|---|---|
| `--bg` | `#0b0d10` | 页底 |
| `--surface` | `#171b22` | 卡片/简历容器 |
| `--text` | `#eef1f6` | **正文（含简历 bullet）** |
| `--text-muted` | `#9aa3b2` | 副文/日期/meta only |
| `--border` | `rgba(255,255,255,0.08)` | 分割 |
| `--accent` | `#7dd3c0` | 链接、当前态、小节强调 |

背景：允许 **极弱** 单侧冷光（opacity ≤ 现行约 50%），禁止双径向「舞台光」。  
主按钮：实心 accent 或浅底深字，**禁止** 线性渐变 + 大投影。

### 字体

| 角色 | 规则 |
|---|---|
| UI / 中文标题 / 正文 | `Sora` + `PingFang SC` / `Noto Sans SC`（中文不走衬线） |
| Display | **仅包英文短词**（如 logo `daner.`）；中文标题禁止 Fraunces |
| 代码 | `IBM Plex Mono` 14px |

### 版式

- 壳宽 `--max: 1080px`；散文/简历内容栏 ≈ `720–760px`
- 顶栏 sticky、模糊可留；导航改 **文字链 + 当前态下划线/轻底**，减 pill 感
- 首页记忆点 = logo 字标 + 一句锋利定位 + 最多 3 个能力词（不是一排 chip 墙）
- 简历：屏上可保留轻容器；打印强制白底、去阴影圆角、藏 chrome

## 4. 参考（气质，不抄皮肤）

- **读**：Linear 文档站的层级克制；Stripe Press / 编辑向个人站的字距与留白  
- **避**：常见「dark + mint glow + gradient button + badge 行」的模板同款  
- 本站差异化：ML Infra / Agentic RL 的工程师可信感，不是创意工作室秀场

## 5. 不做清单（本轮红线）

1. 不回退浅色脚手架皮肤当屏上默认（打印除外）  
2. 不加英雄大图、插画墙、粒子/滚动叙事长动画  
3. 不把技能做成彩色 tag 墙；简历技能保持文本块  
4. 不引入第二套色板/暗亮切换（本轮）  
5. 不做作品集独立页、CMS、评论、多语言  
6. 动效：仅导航/链接/卡片 hover 与页面淡入级；时长 ≤ 200ms，可关、不挡读  
7. 不改业务内容口径（院校/时间线等交内容/产品）；设计只清「可见元注释」的视觉门禁

## 6. 分工与交付顺序（先 Brief 后大改）

| 角色 | 今日产出 | 落点 |
|---|---|---|
| **设计总监** | 本 Brief + 评审标准（见下） | `docs/design/DESIGN_BRIEF_v1.md` |
| **UX** | 首页→简历→Blog 信息架构与内容层级修订（定位句长度、CTA 主次、简历区块顺序） | 建议 `docs/design/IA_REVISION.md`；未批前 UI 不大拆结构 |
| **UI** | token 落地、导航去 pill、按钮去渐变、简历正文对比度、中英混排标题 | `src/styles/global.css` + layout |
| **视觉美术** | 一处品牌签名（logo/点缀图形），去模板光；装饰 ≤1 个母题 | 图形资产或纯 CSS；忌插满 |
| **动效** | 首页/导航微动效规格（属性/时长/缓动/触发）并协助落地 | 规格进 `docs/design/MOTION_SPEC.md`，实现轻量 CSS |
| **主管** | 节奏与本机刷新验收 | 卡 Brief → 改 token → 内容门禁 |

顺序：**Brief 锁定 → UX 结构意见并行 → UI+视觉改 `src/styles` → 动效最后贴规格。**

## 7. 评审标准（过/不过）

**过：**

- 打开首页不像模板站；accent 克制、无双 glow / 渐变 CTA  
- 简历屏上正文清晰；打印预览白底无 nav；无「乱码/以 PDF 为准」类可见字  
- Blog 安静；中文标题无衬线跳变  
- 动效可感知但不抢内容

**不过（打回）：**

- 又加一层光效/插画/动画「冲高级感」  
- 简历对比度回退或技能变 tag 墙  
- 未对齐本 Brief 私开第二套视觉

## 8. 给工程的口径

优先改 `src/styles/global.css` 与 `BaseLayout` 字体策略；结构大改等 UX 一页意见。内容元注释清理由内容/工程执行，设计卡外发门禁。
